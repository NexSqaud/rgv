## Numbered Findings List

### Finding #1 — [HIGH] Empty State for Right Sidebar Item Grid
- **Rule**: `R-27` (UI States) & `antislop-ui` (Placeholder Empty and Loading States)
- **Location**: [`RgvScreenManager.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvScreenManager.java#L291-L315)
- **Reason**: When the search query or craftable filter yields 0 items, the right sidebar grid renders blank without explaining the cause or offering a resolution.
- **Proposed Remediation**: Display an informative empty state text when `pageItems.isEmpty()`: *"No items match filter. Clear search or toggle [C]"*.

### Finding #2 — [HIGH] Empty State / Onboarding Hint for Bookmarks Sidebar
- **Rule**: `R-27` (UI States) & `antislop-ui` (Placeholder Empty and Loading States)
- **Location**: [`RgvScreenManager.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvScreenManager.java#L241-L244)
- **Reason**: When no bookmarks exist (`bookmarks.isEmpty()`), the method returns early, leaving the left sidebar completely blank without an onboarding hint.
- **Proposed Remediation**: Render a subtle placeholder state when bookmarks list is empty (e.g. *"Hover any item and press 'A' to bookmark"*).

### Finding #3 — [HIGH] Actionable Empty States for Recipe & Candidate Selectors
- **Rule**: `R-27` (UI States) & `antislop-ui` (Placeholder Empty and Loading States)
- **Location**: [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L368), [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L763-L779)
- **Reason**: Recipe view renders a bare generic message *"No recipes available."* and candidate recipe selector renders nothing when recipes list is empty.
- **Proposed Remediation**: Provide clear, actionable empty states explaining why recipes are unavailable (e.g. *"Raw material or world drop with no crafting recipe"*).

### Finding #4 — [HIGH] WCAG AA Text Contrast Compliance
- **Rule**: `R-25` (Color Contrast)
- **Location**: [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L368), [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L442)
- **Reason**: Text color `0x555555` on `#C6C6C6` background has a contrast ratio of ~4.35:1 (below 4.5:1 WCAG AA), and inactive tab close 'x' color `0x888888` on `0x2A2A2A` has ~4.3:1 contrast.
- **Proposed Remediation**: Darken light-background text to `0x333333` (contrast ~8.8:1) and brighten dark-background text to `0xAAAAAA` or `0xCCCCCC` (contrast > 6:1).

### Finding #5 — [HIGH] Keyboard Accessibility for Recipe Paging
- **Rule**: `R-32` (Keyboard Accessibility)
- **Location**: [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L1180-L1193)
- **Reason**: Only Escape key is handled; keyboard arrow keys (`Left` / `Right`) cannot cycle recipe pages or tabs without mouse interaction.
- **Proposed Remediation**: Add support for Left and Right arrow keys in `RgvRecipeScreen.keyPressed` to cycle through recipe pages.

### Finding #6 — [MEDIUM] Document Purpose for Graph Viewport Grid
- **Rule**: `R-07` (Background Patterns) & `R-31` (Purpose Test)
- **Location**: [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L531-L546)
- **Reason**: The graph canvas background grid lines (`0x15FFFFFF`) are rendered without an explicit documented design purpose.
- **Proposed Remediation**: Document the explicit purpose of the grid (panning reference markers for node spatial orientation) and maintain subtle opacity.

### Finding #7 — [MEDIUM] Document Color Hierarchy for Graph Nodes
- **Rule**: `R-20` (Visual Identity) & `R-31` (Written Reason)
- **Location**: [`RgvRecipeScreen.java`](file:///c:/Users/NexSqaud/Desktop/emi-1.7.10/core/src/main/java/ru/nexsqaud/rgv/core/screen/RgvRecipeScreen.java#L580-L586)
- **Reason**: Hardcoded node border colors (`0xFFE5B83B`, `0xFF3399FF`, `0xFF77AA77`) lack documented hierarchy definitions.
- **Proposed Remediation**: Document the color hierarchy explicitly in the code: gold for target root, blue for expanded composite recipe, green for craftable raw/leaf.
